# 🎬 Animated Character Intros — Part 1 v3
### Clean shots (NO text) → animate → name reveal in CapCut

## Why no text on the images
AI video tools (Kling/Hailuo) warp any lettering baked into an image.
Clean plate + CapCut text overlay = crisp professional result.

## 🎞️ CapCut assembly per intro (~13-16s each)
1. Animated clip on timeline (if 5-6s clip, loop/extend with second generation or slow it to 0.8x)
2. Narration audio underneath (Durai's voice introduces all three)
3. OPTIONAL minimal text: just the name "DURAI" / "KAVIN" / "MAARAN" in clean white font,
   small, bottom third, fade-in at narration's name-drop moment, fade-out 2s later. No labels, no taglines.
4. Sound design: street ambience under all three; bass drop at each name-drop moment
5. Color: same "Film/Noir" filter ~30% as rest of the film
