## 🎙️ Kling Lip Sync (for scenes 02, 03, 04, 08, 10)
1. Generate the image-to-video clip first
2. Open the result → choose **Lip Sync**
3. Upload that scene's `dialogue.mp3`
4. Kling makes the mouth move with the Tamil dialogue — vera level! 🔥

If lip sync credits run out, no problem — the normal animated clip still looks great with the voice played over it (like a movie dubbing style).

---

## ✂️ Day 3: Assemble in CapCut (free)
1. New project → 9:16 ratio
2. Drop all animated clips in scene order (01 → 12)
3. Add audio: `KURAI_ILLA_DURAI_audio_drama.mp3` (mute the clips' own audio) — OR if you used lip sync, keep each clip's synced audio instead
4. Trim/stretch each clip to match its dialogue
5. Import `english_subtitles.srt` for instant subtitles (CapCut: Text → Captions → Import)
6. Add free SFX from CapCut library: rain loop, police siren (scenes 09-10), tense BGM
7. Export 1080p → post to TikTok/Reels/Shorts 🚀

## ⚠️ Free-tier tips
- Hailuo free = ~6 sec max per clip → for long scenes, generate 2 clips and cut between them (actually looks MORE cinematic, like real film editing!)
- Kling free queue can be slow at peak hours — generate at night MY time
- Watermarks: Hailuo has none; Kling's small logo can be covered with a subtitle bar or cropped slightly in CapCut
- Don't waste credits: write the prompt carefully once, don't re-roll too much
